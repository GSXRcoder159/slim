slim — delete a JS/TS dependency by replacing it with a verified slice

Usage:
  slim <command> [options]

Commands:
  scan              Find packages you only use a few functions of
  inspect <pkg>     Show call sites, envelope, and whether Slim will try
  replace <pkg>     Write a slice, fuzz it against the original, open a PR
  check             Re-run standing tests; envelope still matches call sites
  watch             See if upstream advisories/releases touch your slice
  doctor            Check Node, git, gh, slices, and the watch workflow

Alias:  slim upstream → slim watch

Global options:
  -h, --help        Help for this command
  -V, --version     Print version
      --cwd <dir>   Project root (default: find package.json upward)
  -q, --quiet       No progress on stderr
      --verbose     Extra progress on stderr
      --json        Machine output on stdout; progress stays on stderr

This is not a package manager. It writes files in your repo.

Examples:
  slim scan
  slim inspect lodash
  slim replace lodash
  slim check
  slim watch --write-workflow
